# Published measurements and their limits

The aggregate measurements accompanying author manuscript v8 are in the [supporting information](supporting-information.md). Tables S10 and S15 now cover 36 neural networks; their raw magnitude controls have been excluded. Other valid control comparisons remain.

The original result archive and the internal chronological measurement log are not part of this code release. This page does not assert that those results are absent, and software tests do not recreate the manuscript's numbers. Historical paired-clip equal error rates await checking against the corrected tie-handling implementation.

See [reproduction](reproduction.md) and [publication status](publication-status.md) for the exact limits and remaining checks. No new experimental outcome is claimed by this correction release.
